# EXOApplicationAccessPolicy

## Description

This resource configures Applications Access Policies in Exchange Online.

**DEPRECATED.** Microsoft replaced Application Access Policies with Role Based Access Control (RBAC) for Applications and advises against creating new Application Access Policies. Use the `EXOServicePrincipal`, `EXOManagementScope` and `EXOManagementRoleAssignment` resources (with the `App` parameter) instead. This resource will be removed in a future release.

More information: <https://learn.microsoft.com/exchange/permissions-exo/application-rbac>
